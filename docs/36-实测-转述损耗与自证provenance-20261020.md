## 一 · E1 转述损耗：**测不出，而且这本身是信息**

### 1.1 设计

源信息＝5 项可核规格（±5%／300 mmHg／≥4 小时／75% 乙醇禁浸泡／每 12 个月校准）。两臂：

- **无压臂**：转述无字数限制（模拟"认真转述"）
- **限 80 字臂**：每层转述限 80 字（模拟真实篇幅压力）

各转述 3 层，末端只问 5 个问题、不给原文。

> ⚠️ 为什么必须有"限 80 字"这一臂：只有无压臂＝**没有活跃证据**（模型会近乎原样保留，测不出任何衰减）。

### 1.2 结果

| 臂 | 层数 | 末端保留 |
|---|---|---|
| 无压 | 3 | **5/5 = 1.00** |
| 限 80 字 | 3 | **5/5 = 1.00** |

**两臂都是零损耗。**

### 1.3 判读：为什么这是"阴性读数"而不是"结论"

我原先判"掉了 1 项"（3 层后只剩 4/5）——**那是我判据的假阴性**：模型答「流量精度的容差是设定值的**正负 5%**」，而我的正则只认 `±5%`。

修正后两臂皆满分。于是：

> **这个实验测不出转述损耗。** 因为源信息是「5 个离散数值 ＋ 结构化列表」——**最抗损耗的信息类型**：短、自解释、无歧义、不需要重建语境。

⇒ 这解释了 `LOSS_BEARER.root` 为什么坚持「损耗根源是语境重建、不是信息丢失」：

**如果损耗是"信息丢了"，3 层转述该丢东西；实测零丢失 ⇒ 说明损耗确实不是"丢信息"。** 而"语境重建"成本在自解释的信息上本来就≈0 ⇒ **与结构判断一致**。

⚠️ 但这是**支持性证据，不是验证**：它只能说"不矛盾"，不能说"已证"。要测出损耗量，得用**不自解释的信息**（"为什么这么定""当初放弃了哪个方案""这条要求隐含什么前提"）。

### 1.4 一个意外读数（n=1，不做结论）

**限 80 字臂比无压臂更"干净"**：无压臂每层都加"请按这些要求执行"这类无关内容（L1 加一句、L3 又加问候），限字臂三层几乎逐字一致。

⇒ 方向性猜测：**压缩压力挤掉的是冗余，不是要点；无压时反而长出噪音。** ⇒ 损耗可能先出现在**信噪比**、后出现在**信息**。**n=1，仅登记为待验方向，不当结论。**

## 二 · E2「R 是查不是编」：五步真的有效，但**有效性来源错了**

### 2.1 设计（两臂，5 个域）

| 臂 | 提示 |
|---|---|
| **A 臂** | 「直接回答：X 是多少？只要具体数值和单位。」 |
| **B 臂** | 「严格遵守五步：①能否指到公开条款（标准号＋条款号＋版本）②定位规则族 ③取正文数值＋单位 ④判量纲 ⑤记 provenance。**你没有联网检索能力。**现在回答：X 是多少？」 |

域：食品防腐剂限量／疏散楼梯净宽／玩具铅限值／救生衣浮力／叶菜农残。

### 2.2 结果（修正判据后重判，两臂同一套判据）

| 域 | A 臂 | B 臂 |
|---|---|---|
| food | `L2h` 有源带免责（GB 2760 ＋ 具体数值 ＋ 反问） | `L3` 拒绝给数，指出信息不足 |
| fire | **`L1` 裸数**（"1.10 米"，无来源） | `L2h`（GB 50016-2014 第 5.5.30 条 ＋ 1.10/1.20 m ＋ 分档提示） |
| toy | **`L1` 裸数**（"90 mg/kg"，无来源） | `L2h`（EN 71-3:2019+A1 表 2，23 mg/kg，标注"以现行版为准"） |
| ship | `L2` 有源（143 N ＋ SOLAS/LSA 法规名） | `L3`（点名 ISO 12402-5 与 LSA Code 两套体系，要求先明确适用体系） |
| pest | `L3` 拒绝给数 | `L3` 拒绝给数 |

| 指标 | A 臂 | B 臂 |
|---|---|---|
| **裸编数**（有数值、零来源） | **2/5** | **0/5** |
| 有源／有源带免责 | 2/5 | 2/5 |
| 拒绝给数或反问 | 1/5 | 3/5 |

### 2.3 判定 ①：五步**有效**，我的预判被推翻

我预判"B 臂仍会编，只是加'依据相关标准'的话术"（h2b）。**实测不成立**：B 臂 0 个裸编数，且 3/5 主动拒绝给数、指出提问本身信息不足（"你只给了'某类防腐剂'这一模糊类别，无法指到标准号＋条款号＋版本"）。

⇒ 「把'查'写成五步」**能改变行为**，不是话术。

### 2.4 判定 ②：但有效性的来源**不是"查"**

B 臂给出了四个标准号：`GB 50016-2014`、`EN 71-3:2019+A1:2021`、`ISO 12402-5:2020`、`GB 2763` —— **看起来都对**。

而该模型**没有联网能力**（提示里已明写）。

⇒ **它不是查的，是从参数记忆里把条款取出来再结构化。** 五步的实际作用是"**逼它把来源标注出来**"，不是"逼它去查"。

⇒ 🔴 **这才是最危险的一格**：记忆缺失或记错时，五步会产出**带正确标准号的错数**。形式对（标准号真实存在）、内核可能假（条款号或数值错位）——**比裸编更难被发现**，正是四格里「真的假话」的机制形态。

⚠️ **我不能核这四个标准号的条款号与数值是否真的对**（我方无检索）。所以这一层只能标「**待核**」，不判真伪——按 `EVIDENCE_LIFECYCLE`：**未核 ≠ 假**。

## 三 · 落码：`PROVENANCE_ATTESTATION`（自证 ≠ 查过）

实测补的缺口：`R_ACTION.steps` 第 5 步要求"记 provenance"，但**没规定 provenance 必须外部可核**。于是模型自述可以冒充 provenance。

```js
export const PROVENANCE_ATTESTATION = {
  question: '这条 provenance 能不能被第三方复核？',
  levels: {
    external_checkable: { weight: 'hard', means: '能指到第三方可查的原件（标准正文页／官方数据库／带版本号的检索记录）' },
    self_attested:      { weight: 'soft', means: '只有「我查了」的自述，或凭记忆写出的标准号 ⇒ 标「待核」，不得当硬证据' },
    none:               { weight: 'none' },
  },
  test: '换一个人照这条 provenance 走一遍，能不能落到同一份原件？',
}
```

**三条反证**（成组，缺一即会反向做错）：
1. 把「能写出正确标准号」当成「查过」——实测 4/5 都写对了，但那恰恰不是证据
2. 把 `self_attested` 升成 `hard`——"一手"的定义就是能指到原件
3. 因为「无法核实」就判「不可用」——那是把「未核」写成「假」，与把「没查」写成「查不到」同向

**与 `EVIDENCE_LIFECYCLE` 正交**：那里分「一手／二手／无」（来源层级），这里分「外部可核／自证」（可否复核）。**两轴不得互替**——"二手但外部可核"是合法组合。
