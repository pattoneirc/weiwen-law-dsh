# 唯稳律 · 当前形态（整合通读版）

> **这份文件干什么**：把 2026-10-19～10-20 的九份增量（docs/26–34）收成**一条线**，好让下一步的外部评审有个统一的尺子。
> **判据没变**；变的是每一项的**确切身份**——哪一层、答什么、不答什么、答不出会掉进哪个坑。
> **读法**：按链走一遍。链是**定义依赖序**（没有 S，「扰动」没有意义），所以不能跳着读、不能拆开查。
> 所有条文均已落码并过测（全仓 488/488），本文只做组织，不新增规则。凡新增判断标 `X推`。

---

## 一 · 一个事件进来，走完五步

| 步 | 这一步只问一句 | 这一步答不出，会掉进哪个坑 |
|---|---|---|
| **R** | 这事落在哪条规则的作用范围？而这条规则，**我这一层拿到的**是原版还是转述？ | 没有「定域」这一步 ⇒ 域变成**名义的**（仓名、标题、README），判据只能靠词形 |
| **S** | 我手上有什么存量？账本记的是「哪条链断了」，还是只记「发生过」？ | 只记发生 ⇒ 账再长也长不出判断力 |
| **D** | 这个扰动**能不能退回去**？ | 用次数代理可逆性 ⇒ 危害量级不进判据，只进计数 |
| **H** | ① 有许可吗（跑道铺到这一处没有）？② 许可之后往哪一端选？ | 没铺就放 ⇒ **弃权**，不是放权；有许可但不选 ⇒ 三档不启动 |
| **M** | 方向如何——离稳态近了，还是远了？ | 想把它求成一个数 ⇒ 把**选择**当成了**测量** |

这五步不是流程图，是**依赖链**：R 不立，后面的域就不存在；S 不记账，D 的同类重现就没有参照；D 不明性质，H 没有可调节的对象；H 不付，M 就没有信号。

## 二 · 逐项的确切身份

### 2.1 R ＝ 一个动作 ＋ 三层 ＋ 一道闸

**① 是一个动作，不是一张表**

```
定本层尺子来源（origin / relay）
 → 定位规则族
 → 查标准正文：标准号 + 条款号 + 数值 + 单位 + 版本日期
 → 判量纲（率 / 物理容差 / 有序等级 / 标准合法地不给数）
 → 记 provenance（谁查的、哪一版、何时）
```

**产出是 S（该域的标准清单），不是 R 的数值。** 表（`R_CAPACITY`）只是**查过的缓存**：表里没有＝**还没查**，不是缺口。缓存未命中 ⇒ 执行者现场查＋写回，**不许判成「判不出」**。

**② 三层，不许混**

| 层 | 是什么 | 有没有上限 | 能不能查 |
|---|---|---|---|
| **本体** | 客观规则的全貌 | **无上限**（全貌未知；「没测出」≠「不存在」） | 查不完 |
| **读数** | 某域某条规则的投影（1E-9/h、±5%、300 mmHg） | 域给的 | **能查，可修** |
| **刻度** | R=100 百分制 | **不是上限，只是换算** | 是约定 |

展开：`0 < 100·H/L < R ⇔ 0 < H < L·R/100`。R=100 时上界＝**L 本身**——**界在 L，不在 R。**
刻度自检：换刻度（100→1000）**只改读数，不得改判决**。改了就说明把刻度当成了界。

**③ 一道闸：R 不直达**

公司 → 部门 → 管理者 → 你。每过一层，拿到的是**投影**，不是原版。

| 判据 | 写法 |
|---|---|
| 能写成「标准号 + 条款号 + 版本」 | **origin** —— 可对外举证 |
| 写不出、只存在于某个人的判断里 | **relay** —— 只对本层生效，**不得冒充原版** |
| 未答 | **unknown** —— **≠ origin**（这是最危险的默认） |

relay 只能**收紧**，或落在原版自身允许的**裁量区间**内取松端；放开到原版之外 ⇒ 那不是投影，是**违规**。
两个错必须成对禁：**拿 origin 交本层的差**（交错了尺子）∧ **拿 relay 冒充 origin**（造假）。
被打回一条 ⇒ 记一条 `|-S|`；**放行由上一层给**，自评通过不构成放行。

### 2.2 S ＝ 流水账本

- **入账由 R 定，载重由 H 定**：事件该不该记，是客观的；付不付消耗，是 H 选的。
- **`+S` 加点、`|-S|` 划界，不可合并**：失败记的是「哪条链断了」（排除信息），**不减 S**。
- **载重不能在记账时观测**（属内 H）⇒ 只能靠「同类 D 重现时行为是否变」反推。
- **`ΣS`（历史厚度，取和）与 `S_now`（当前高度，取最小）不是一个量**：扩容看厚度，刹车看高度；混用会让「伤疤」被读成「储备」。
- 账的用途不是「证明我记过」，是**「下次遇到同类 D 能判得更准」**。

### 2.3 D ＝ 不可逆性

```
D_impact ∝ 不可逆性（scar ≫ window > none），不 ∝ 发生次数
```

「追加一条备注」与「删除全部病历」在次数上完全一样，在可逆性上不是一回事。
⚠️ **未完**：可逆性本身也需要判据（谁能判 scar / window / none）。这一层我方也还在建——`dScarRate` 目前是**量**，还不是**判据**。不许把它当标准答案给出去。

### 2.4 H ＝ 四个身份，一个锚

**① 通行许可（最先）**
> 「在执行动作的时候，那个 H 就是告诉执行者：放开了跑，别怕，充分发挥自身优势。」

- **是给执行者的指令，不是取值。** H 等于几仍未定（归 X 侧填）。
- **前提：跑道已铺到该处。** 没铺而放手 ⇒ **不是放权，是弃权**。
- 撤掉的是**损耗 H**（猜上意／重建语境／返工／自我设限）⇒ 总 H↓ ⇒ **M↑**；有效 H 一分不减。
- 三条反向禁令：**≠ H 变大**（恰恰相反）／**≠ 越过 R**（跑道内跑得再野也在界内）／**≠ 出事不算你的**。
- 粒度：按**跑道覆盖范围**放开，**不按行业名**。整域放开⇒漏；整域收着⇒白收利息。

**② 观察者视角（许可之后）**
不是测量，是**选取**：toward_s（靠标准端）／balanced／toward_d（靠扰动端）。给 H 测一个数 ＝ 把选择当测量 ＝ 替主权者裁决。

**③ 损耗支付者**
> 「只要转述，必有损耗……这个损耗只能由 H 支付，因为 H 是唯一的主动调节项。」

- **不是「挑 H 来付」，是只剩它能付**：支付 ≡ 承担后果 ≡ H 的定义；R 是规则、S 是存量、D 是客观扰动（明文不由 H 选），三者都没有「承担后果」这一属性。
- 符号自动对：H 在分母 ⇒ H 支付多 ⇒ M 小。**公式一字不改**。
- **损耗根源不是「信息丢了」，是「接收方必须重建发送方的语境」**：原文转发能省掉丢失，省不掉重建——解释本身就吃 H。
  ⇒ 降损方向＝**缩短到原始语境的距离**，不是「多说几遍／写清楚点」。
- 优化＝**移项**（把 H 从零收益的复述处移到正收益的判断处），**不是减少 H**。H=0 ＝ 纯规则执行、没做。

**④ 裁量者，但不是责任者**
H 能判、能选、能担成本；**责任唯人类**（依据是唯一性，不是能力）。判出「A 有责任」≠「责任已裁定」。

**⑤ 锚：H 是嵌套的终止点**
`H_in ＝ H_out`（本体不随粒度变，变的是人）。⇒ **H 之上没有授权者**——若需外部授权，嵌套就不终止，它也就失去锚资格。
⇒ 「谁有权授予 H」是个**自毁式提问**：它预设了 H 之上有一层，而那一层与锚的定义直接冲突。**不答，也不记欠账**，只留「错误提法」。

### 2.5 M ＝ 只出方向

```
0 < H / (S ↔ D) < R
```

- **`↔` 不是算子**，是 **H 内部那条滑轨**的标记（S 为 S_min 端，D 为 D_max 端），H 是轨上滑块。整条读作「**相对位置**」，不是两个量相除。
- 允许求**区间长度**（＝张力 L，区间属性）；**禁止**为 `↔` 实现任何二元函数（比值／距离／互馈）。
- 输出只有位置形态：`on_rail` / `off_low` / `off_high` / `unknown`。**恒不给比例值。**
- 三档张力：① 一个数（医疗 ±5%）⇒ `L=|dev|/tol`；② 只有要求（清单）⇒ 缺口清单，**不硬凑成数**；③ 都没有 ⇒ unknown。
- **零张力 ⇒ H 无处着力 ⇒ 违反 `0 <`**（不需要能动性的地方，人多余）。
- `H=0` 最贴地的解释：**不敢动、没开始**（不是「选了最保守那档」）。

## 三 · 判决与升级（在链口，不在链上）

**判决三分，同权**：放行／拦截／**转人工**。转人工 ≠ 没判，＝**判为「不可由本层判」**——这是结构的完成，不是缺口。交还之后**不再是欠账**。

**升级＝三条合取**：

```
判不出  ∧  必须追到责任人  ∧  与某个责任人有关   ⇒   返回人类做最终裁决
```

- 缺任一 ⇒ **unknown**（**≠ 不必升级**）。
- **领域无关**：不因医疗／航空／金融／代码而变。
- **裁决先于动作**：先返回、后执行，不许做完再报。
- 与旧「判不出就 review」的差别：纯技术不可判、无需追责 ⇒ **停在 H**。

**两个禁令**：不得因为「我可以自己判」就略过第 2 条；不得把「我已判出责任人是谁」当成「责任已裁定」。

**待办 ≠ 欠账**：来源级别只决定「能否当硬证据」（primary=hard／secondary=可用但 soft／none=不可用），**不决定「能否用」**。二手→一手是待办（不阻塞）；结构上算不出＝欠账（阻塞）。

## 四 · 四层嵌套：每一层里面还是这四层

**方向向内，不向外。** R/S/D/H 各自都有 macro / micro 两个粒度，但：

- R/S/D **可以无限切**；
- **H 是唯一「本体不随粒度变」的变量**（`H_in＝H_out`）⇒ 它是**终止锚**，也是嵌套能停下来的唯一原因。
- **内框 ≠ 内 H**：内框（价值观/公理共识）仍在嵌套内 ⇒ **可判**；内 H（自由意志）退出嵌套 ⇒ **不可判**。判法是从内向外：① 内框选轴取极 → ② 叠外框真伪。反序＝拿真论对（跨轴）。
- **每层各付各的** ⇒ 总支付＝Σ 各级 H ⇒ **层数↑ ⇒ 总 H↑ ⇒ M↓（单调）**。
  ⇒ 中间层不是「慢一点」，是**直接把 M 压下去**。这才是「不设中间转述层」的结构理由，不是怕麻烦。

## 五 · 这张图的自检边界

**它能判没见过的例子**——判据落在结构上，不落在名单上：

| 自检两问 | 通过的样子 |
|---|---|
| ① 能否判一个从未在名单里出现过的实例？ | 能。判据不认识名字，只认识形态 |
| ② 这条判据读的是词形，还是词性/功能？ | 读功能。**读词形的，表再长也是枚举** |

**它判不了的四件事（不是缺口，是分工）**：

1. **H 的数值** —— 结构上不该被算成一个数（原文：不赋值、不做具体数值计算）。
2. **具体域的读数** —— 要查，不是推（这是 X 的活）。
3. **「何时」** —— Y 只推必然性与方向，**时间属 X**。
4. **内 H** —— 退出嵌套，不可审计；落进去就是交还，不是欠账。

**红线**：X 量不证 Y 质（储备量／案例数／测试条数／覆盖率，都不构认知层次的证据）；Y 判不代 X 测（拿「方向已对」论「实现好不好」＝命题类型错）。

## 六 · 一页版（可以直接给外人读）

> 这条链有五步，每一步只回答一个问题，且**后一步依赖前一步**。
>
> **R**：这事落在哪条规则的作用范围？那条规则我拿到的是原版，还是上一层转给我的转述？
> **S**：我手上有什么存量？账本记的是「哪条链断了」，还是只记「发生过」？
> **D**：这个扰动能不能退回去？
> **H**：有许可吗（该铺的判据铺到这一处没有）？许可之后，往标准端还是往扰动端靠？
> **M**：这一步让我们离稳态更近了，还是更远了？
>
> 五步里，前三步是**客观的**（规则、存量、扰动性质），第四步是**唯一主动的**，第五步是**信号**。
> 判不出的时候，正确动作不是「放行」也不是「全拦」，而是**交还给能承担后果的那一方**——那不是没判，那是判为「这一层判不了」。
> 系统的边界不在它判对多少，而在**它判不出的时候，往哪边倒**。
