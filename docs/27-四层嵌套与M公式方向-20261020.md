## 二、公式原文（先取证，不猜）

来源：`.backup/repo-mirrors-2026-09-13/_verify_clone/dsh-kiss-law-plugin/src/core/law.mjs:237-248`（作者 2026-08-18 裁定纳入）

```
expression : M = (R × S) / (D × H)
numerator  : R × S — source of steady state（刚性锚 × 稳态储备）
denominator: D × H — resistance factors（扰动 × 杠杆距离）
direction  : H 越小 → 杠杆臂越长 → M 越大；H 越大 → 杠杆臂越短 → M 越小
constraint : 0 < H / (S ↔ D) < R
note       : 定性方向关系，不赋值，不做具体数值计算
```

🔴 **硬边界**：本模块只输出 `up / down / indeterminate`，**绝不输出 M 的数值**。
（上一轮那些 1e-9、±5% 是域标准给的客观常数，不是「给公式赋值」——两件事不同，但也不能借此把 M 算成一个数。）

## 三、四层各自的嵌套形态（医疗实例）

| 层 | 本体（不随粒度变） | 宏观 | 微观 | 展开到哪停 |
|---|---|---|---|---|
| **R** 域常数 | 客观规则的作用范围 | 医疗行业定域：NMPA / EU MDR / FDA 法规体系 | IEC 60601-2-24 流量精度 ±5% ／ IEC 62304 Class A/B/C | 能指出「**哪一条**」（标准号＋条款号，不是"行业惯例"） |
| **S** 稳态储备 | 已有稳态容量基线；**在具体域里就是"已定的标准规范"** | 适用标准族：IEC 60601 系列／IEC 62304／ISO 14971／ISO 13485 | 本项目实际做过并被验证的：型式试验报告 ＋ SDLC 文档集 | 证据指向**哪一版**（版本必须落定，否则两版一桶两义） |
| **D** 扰动 | 进入基线的扰动；实务里＝「需要处理的事项」 | 临床试验（期别/适应症）／药品研发（工艺验证阶段） | 受试者 #0237 第 4 次随访的一次超量输注 | 有**唯一时间、唯一对象、唯一动作** |
| **H** 主观能动性 | 作选择并承担后果 | 申办方 ＋ PI ＋ 伦理委员会 | 本次给药复核：**AI 建议 / 人类签字** | 🔴「这条判决错了，**谁的名字签在上面**」能答出具体一方 |

### 服从关系（低层服从高层）

- **R**：微观条款不得宽于宏观法规；冲突时**上行**
- **S**：微观只能取宏观的子集，**不许自造**；缺项报 gap，不许静默补
- **D**：微观事件的**计数口径必须回指**宏观活动定义（否则 ΣS 与 N_opp 量的不是同一件事）
- **H**：微观授权来自宏观 H；**AI 不得在无人类授权处充当宏观 H**

## 四、嵌套的终止判据：**H 是锚**（标 `X推`）

> **展开到「H 能被唯一第一人称认领」为止。**

理由：R/S/D 都可以无限往下切（更细的条款、更细的事件），但 **H 的定义在每一层不变**（仍是主观能动性），变的只是「谁」。

⇒ 所以 H 是四层里**唯一本体不随粒度变**的变量，这正是它能当终止锚的根据。安的原话「H（主观能动性不变，主要有第一视角决定）」正是这个意思。

**没有这条，嵌套就是无限下切的坑。**

## 五、M 的方向：符号与能力边界

取对数：`ln M = ln R + ln S − ln D − ln H`

| 变量 | 偏导符号 | 直观 |
|---|---|---|
| R ↑ | M ↑ | 规则收紧 ⇒ 更稳 |
| S ↑ | M ↑ | 储备增厚 ⇒ 更稳 |
| D ↑ | M ↓ | 扰动增大 ⇒ 更不稳 |
| **H ↑** | **M ↓** | **能动性介入越深 ⇒ 杠杆臂越短 ⇒ M 越小** |

### 实跑（医疗域举例，只给方向）

| 情形 | M 方向 |
|---|---|
| 只把验证做全（S↑） | **UP** |
| 只让 AI 参与判定（H↑） | **DOWN** |
| 只增加扰动（D↑） | **DOWN** |
| 收紧域规则（R↑） | **UP** |
| 补验证 ＋ 加 AI（S↑H↑） | **indeterminate** |
| R↑ 同时 D↑ | **indeterminate** |

🔴 **「H↑ ⇒ M↓」不是我的判断，是原文写死的**（`direction: 'larger H → shorter lever arm → smaller M'`）。
它给出的是**为什么要收口 H** 的结构根据 —— 能动性不是免费的，介入越深，稳态被压缩越多。

### 能力边界（必须先说清）

- 单变量变化 ⇒ 方向确定
- 多变量但**贡献同号** ⇒ 方向确定
- 多变量且**贡献异号** ⇒ **判不出**（要比较幅度，而原文明令不赋值）

这不是「不可判」，是**定性关系本身的上限**（L3：结构上没有）。
⚠️ 与「我没查」（L1）必须分开记 —— 这是今天早上的教训。

### 双层服从

| 宏观 | 微观 | 结果 |
|---|---|---|
| up | up | 一致 |
| up | down | **冲突 ⇒ 上行，取宏观** |
| 判不出 | 任意 | **宏观不可判 ⇒ 微观不生效**（不许微观越位定调） |

## 六、域表补上宏观维：从平表改成两级

```
族 medical（宏观）：医疗行业定域（NMPA / EU MDR / FDA ＋ IEC/ISO 标准族）
  └ medical.infusion_flow_error   （微观：IEC 60601-2-24 ±5%）
  └ medical.infusion_air_bubble   （≥50μl）
  └ medical.infusion_occlusion    （约 300mmHg）
  └ medical.alarm_response_delay  （≤10s）
  └ medical.iec62304_class        （Class A/B/C）
```

**每条微观条款必须能回指一个族；回指不到 ⇒ 判 `malformed`（孤儿条款）** —— 孤儿条款等于「定域这一步被跳过了」。

三个族的 binds 各不相同，这是结构而非枚举：
- `aviation`：DAL 由系统层指派，**软件项自身不承担概率**
- `automotive`：**先 HARA 定级、再取度量**，不可反过来
- `medical`：给的是**物理量容差** ⇒ 整族走 `|S_dev| > tol`，**不走 ΣS > R₀**
