# 32 · R 不直达：本层的尺子与放行

> 来由：安 2026-10-20 16:4x 亲自举的一个例子。**不是比喻，是实物** —— 它照出了我上一轮写错的两处。
> 落码：`src/core/verb.mjs` 的 `R_RELAY` / `rSourceGrade` ＋ `R_ACTION.steps` 补第 1 步；测试 ㊲–㊷（全仓 474/474）。

---

## 一、例子原文（保留，它是判据来源）

> 「假设我在一个公司部门上班，就是一个基础职员，公司下达了一个项目任务，刚好由我这个部门接手去做。然后部门管理者就开始下派任务，分到我手上就是做文案和 PPT。我作为做这个任务的第一责任人，我有我自己的审美和思维方式，在做任务的时候就会自动带入我的审美和思考能力。等我文案和 PPT 做好了以后，**我不是直接交给公司，而是交给部门管理者**，由他审核我做的符不符合标准，能不能过，不过的地方，我需要修改调整，直到管理者放行。」

层：**公司 → 部门 → 管理者 → 我**。

---

## 二、它照出我错在哪

### 错 1：R 不直达 —— 我把第一步写成了「查公开标准」

我原来的 `R_ACTION.steps` 是：定位规则族 → 查标准正文 → 判量纲 → 记 provenance。

照那个跑，我会做的是：查国标 → 按国标写文案 → 交上去。**然后被管理者打回。**

因为约束我的不是国标，是**管理者那把尺子**。它是公司标准经他理解后转述下来的一版，可能更严、可能漏项、可能有他自己的取舍。

⇒ **「R 是客观规则」这句话必须精确到层**：

| 说法 | 成立范围 | 含义 |
|---|---|---|
| R 客观 | **层内** | 对本层硬、不可改、不服从就过不去 |
| R 是投影 | **跨层** | 我拿到的是上层的转述版，不是原版 |

这两个不矛盾，说的是两件事：一个说「对我有多硬」，一个说「它是从哪来的」。

⇒ 所以查域的第一步不是查标准，是**先问这把尺子是谁给的**：

- 能写成「标准号 + 条款号 + 版本」 ⇒ `origin`（公开原版）
- 写不出来、只存在于某人的判断/习惯里 ⇒ `relay`（上一层转述）

判据刻意不看行业名、不看说话人 —— 只看「指不指得到公开条款」。这样它能判一个我没见过的例子。

### 错 2：H 不是空位 —— 「自动带入我的审美」

「**自动**带入」这三个字是判据：H 不需要谁批准，一出手就带着它。

这正是 `H_AUTHORITY.noHigherGrantor`（H 之上无授权者）的实物 —— 不是条文，是每天都在发生的事。

而且它有**稳定取向**（审美、思维方式），不是随机噪声 —— 否则管理者根本无法审核。⇒ H 可被外部**间接**观测（通过产出的一致性），但不可被外部规定。

## 三、顺手印证的两处（不新增，只对齐）

| 例子里的动作 | 代码里的对应 |
|---|---|
| 「直到管理者放行」 | 放行是**上一层**给的 ⇒ 自评 M 通过**不构成**放行 |
| 「不过的地方修改调整」 | 打回一条 ⇒ 记 `\|-S\|`（哪条链断了），**不是扣 S** |

## 四、落码

```
R_ACTION.steps[1]  ←  定「本层尺子」是谁给的：公开原版，还是上一层转述
                   ⇒ 产出 rGrade（origin / relay）
（原四步顺延为 2–5；derived 同步改指 step4）
```

```js
R_RELAY = {
  grades: { ORIGIN:'origin', RELAY:'relay' },
  test: '把这条要求写成「标准号+条款号+版本」：写得出 ⇒ origin；写不出 ⇒ relay。',
  tightenOnly: 'relay 只能严于或等于原版，或落在原版**自身裁量区间**内取松端。',
  anti: [ '拿 origin 交本层的差（交错了尺子）', '拿 relay 冒充原版对外举证' ],
  onReject: '打回记 |-S|；放行由上一层给。',
}
```

**两个错必须成对禁**：只禁一个，就会反向做错 —— 禁了「冒充原版」，人就会拿原版去交差；禁了「交差」，人就会心安理得地把 relay 当标准。

`tightenOnly` 里「区间内取松端」这一句是接线用的：它把 relay 的合法性挂回 `H_OBSERVER` 已有的三档（toward_s / balanced / toward_d），**没有新造一条规则**。否则会把合法裁量一并锁死。

## 五、遗留（不阻塞）

1. `relay` 的 provenance 若「指不到任何原版」怎么办 —— 现在按 `EVIDENCE_LIFECYCLE.none` 处理（不可用，只当线索）。是否要单独一档「黑箱要求」，待议。
2. 多级 relay（公司 → 部门 → 管理者 → 我，可能还有组长）会**每级损耗一次**，损耗如何记账未形式化。
3. `R_RELAY` 与 `R_ONTOLOGY` 的关系已在 `wiring.toOntology` 写明（一个说规则有多大，一个说我这层拿到哪一版），但**跨层一致性**（三级 relay 是否收敛到同一原版）尚无判据。
